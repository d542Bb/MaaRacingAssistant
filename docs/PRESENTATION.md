## 二、演示物料清单

### ① README 首屏动图（P0）
- **素材**：`sidecar.get_peep_frame` 提供的 PEEP 实时预览帧（JPEG base64，数据页内嵌轮询 ~10fps）。
- **做法**：录一段数据页预览窗口 + 自动出价的屏幕录制 → 转 GIF（建议 640×360，≤2~3MB）。
- **放置**：`README.md` 简介小节下方，一句 caption + GIF（GitHub 对 GIF 首屏支持最好）。
- **脚本**：见「三、讲稿要点」场景 B。

### ② 功能截图墙（P0）
推荐 3 张核心图（放 README「已实现模块」附近或 Wiki）：
1. **GUI 主控**：左栏「当前阶段」12 阶段列表 + ▶ 指示器跟随、右侧结束按钮、版本号。
2. **数据页·今日看板**：场次 / 胜 / 负 / 我方利润 / 收入 / 最高单场 + 今日蛋总数（红黄蓝分色）。**这是「自动化有结果」的最直观证明。**
3. **数据页·PEEP 实时预览**：内嵌 16:9，右栏固定，体现「看着机器在玩」。

### ③ Release Notes（P1）
- 主文档已具备 `docs/update_log.md`（按版本叙事），发版时抽最近一段 + 配 2~3 张截图即成本版 note。
- Note 结构：`一句话定位 → 新功能 bullet（鉴宝出价 V3 / 彩蛋识别 / 今日看板 / 启动便利）→ 工程质量（单测+CI）→ 合规声明 → 已知限制（极速狂飙 dev）`。

### ④ CI 徽章（P1）
- 在 README 顶部徽章区补：`tests passing`（GH Actions badge）。发正式版时再加 `release` 徽章。
- 这是「发布前的一道门」在社区面的可视表达。

### ⑤ 短视频 / GIF 帖（P1）
- 30~60s 无剪辑录屏：双击快捷方式 → UAC 提权 → GUI 加载 → 选中鉴宝 → 点开始 → 自动跑完出价结算。首尾压「免责声明」。
- 发帖配一张封面：PEEP 预览帧 + 标题「无人值守自动鉴宝 30s 看懂」。

## 三、讲稿要点

> 给两种时长：**3 分钟快讲**（发布预告/社区帖）与 **5 分钟完整版**（直播/分享会）。
> 讲稿措辞主动落在「技术研究 / 教学演示」定位，不承诺商业与排名相关效果。

### 开场 Hook（30s）
> “MaaRacingAssistant —— 一个模块化游戏自动化平台。它不修改游戏、不读内存，只做「看画面 + 模拟操作」两件事：用视觉识别看懂屏幕，再用虚拟手柄替人工点几下。今天这 30 分钟里，你会看到它在巅峰鉴宝活动里”自己跑完一场“。”

### 逐卖点讲词（每条 20~60s，带演示动作）

1. **模块化架构（一句带过，留谈资）**
   - 讲词：平台用能力接口（capture / gamepad / lifecycle）把每个活动模块和宿主隔开，资源所有权统一治理——模块独立开发、安全组合、退出不泄漏。
   - 演示：无需现场演示，放一页架构图即可。

2. **场景 A · 12 阶段全链路闭环（主线）**
   - 讲词：从游戏大厅到分红结算，12 个阶段 status machine 自动流转，任一阶段可断点续跑。
   - 演示：GUI「当前阶段」列表，▶ 指示器随阶段前进；中途手动停，再从当前位置继续。

3. **场景 B · 实时预览 = 眼见为实（P0 最出彩）**
   - 讲词：机器在看什么、识别到什么，右侧预览全程直播——它不是黑盒。
   - 演示：切到数据页 PEEP 预览，放大到全屏，讲这帧识别到了哪个槽位、估值多少。

4. **场景 C · 智能出价策略 V3**
   - 讲词：不是闷头加价。策略读对手历史最高出价估算「加价意愿」，动态收缩缓冲；带兜底上限防意外接盘；支持赚钱 / 赚蛋双模式。
   - 演示：GUI 切换策略模式，看估值/兜底配置联动；debug HUD 显示与决策同口径的策略估值。
   - 谈资（可选）：对手意愿系数 ×0.3/×0.6/×1.0 分档；双层动态缓冲 = 价格分桶 × 利润强度缩放；估值系数实测校准 → 决策和画面 HUD 同口径。

5. **场景 D · 结算与彩蛋识别**
   - 讲词：结算弹窗中标/未中标判定 + 今日最高 + 奖励彩蛋（红黄蓝蛋）合并识别；竞态修复后不挑帧、不漏记。
   - 演示：跑完一场，看今日看板各项数字 + 蛋总数在结算后跳变。

6. **场景 E · 数据看板**
   - 讲词：每次结算写入本地 `treasure.db`，凌晨 5 点日界，3s 轮询的今日看板直接把战果摆出来。
   - 演示：切数据页，指场次/胜/负/利润/蛋。

7. **场景 F · 上手与工程质量（拉好印象）**
   - 讲词：仓库 clone 到任意位置都能跑——exe 从基目录自动找 `pyproject.toml`，双击快捷方式 UAC 提权即起；发布会前有 `pytest` 单测 + GitHub Actions 把关。
   - 演示：快速开始四步（或跳过，讲一句话即可）。

### 时间轴示例
- **3 分钟快讲**：Hook(30s) → A 12阶段(40s) → B 预览(40s) → C 策略(30s) → D/E 结算看板(30s) → F 上手/质量(20s)。
- **5 分钟完整版**：3 分钟版 + 每场景追加演示动作 + C 谈资(60s) + 结尾合规声明 + Q&A。

### Q&A 准备（社区高频）
| 问题 | 应对要点 |
|------|---------|
| 会被封号吗 / 合规吗？ | 回归免责声明：仅画面识别+模拟输入，不读内存不改文件，仅供学习/教学；账号风险自担。 |
| 识别的技术栈？ | YOLOv8 ONNX（目标/标线 + DirectML GPU 推理）+ RapidOCR（金额/文字）。 |
| 多平台 / 多游戏？ | 模块化平台定位：新增活动只需写一个 capability 模块，框架复用。 |
| 开发的实时看板是读游戏数据吗？ | 否，全部来自画面 OCR + 本地落盘统计，不抓包。 |
| 极速狂飙能用吗？ | 明确 dev 状态，不建议主用，仅技术演示。 |
